Splash sequence. Two halves, one word.

On a white ground, FOR and ya travel in from opposite edges and meet on the baseline. A single flame hairline marks the join, then goes. Everything below is read from one set of values, so the demo, the frames and the table can't drift apart.

The beats

Quarter speed is for reading the motion, not a second spec — the real sequence runs at the durations in the table.

  1. 0 msWhite. Nothing on screen. The ground is already painted by the native launch screen, so there is no flash.
  2. 60 msBoth halves start together, blurred and transparent, 200 px outside their resting positions.
  3. 60–620They decelerate hard into place. FOR tightens from −0.01em to its true −0.06em as it lands, so it reads as compressing into the lockup rather than sliding under it.
  4. 520 msThe flame hairline snaps up on the join, 60 ms before the halves settle — it meets them rather than following them.
  5. 780 msHairline gone. The wordmark holds, fully settled, for 400 ms.
  6. 1180 msHandoff: the lockup falls back to 95.5% and fades as the first screen rises into place.

Drop-in CSS

/* FORYA splash — white ground, charcoal lockup, one flame seam. */
.splash { position:fixed; inset:0; background:#FFFFFF;
           display:grid; place-items:center; z-index:9999 }
.lockup { display:inline-flex; align-items:baseline; line-height:1;
           font-size:54px; color:#18181B }
.lk-for { font-family:'Bricolage Grotesque'; font-weight:800; letter-spacing:-.06em }
.lk-ya  { font-family:'Instrument Serif'; font-style:italic; letter-spacing:-.02em;
           padding-left:.02em }
.lk-seam { position:relative; width:0; align-self:baseline }
.lk-seam b { position:absolute; left:-1px; bottom:-.02em; width:2px; height:.74em;
             background:#F05A1E; border-radius:1px; transform-origin:50% 100% }

@keyframes fy-for {
  from { transform:translate3d(-200px,0,0); opacity:0; filter:blur(7px); letter-spacing:-.01em }
  to   { transform:translate3d(0,0,0); opacity:1; filter:blur(0); letter-spacing:-.06em } }
@keyframes fy-ya {
  from { transform:translate3d(200px,0,0); opacity:0; filter:blur(7px) }
  to   { transform:translate3d(0,0,0); opacity:1; filter:blur(0) } }
@keyframes fy-seam {
  0% { transform:scaleY(0); opacity:0 } 34% { transform:scaleY(1); opacity:1 }
  100% { transform:scaleY(1); opacity:0 } }
@keyframes fy-lift {
  from { transform:scale(1); opacity:1 } to { transform:scale(.955); opacity:0 } }

.lk-for   { animation:fy-for 560ms cubic-bezier(.16,1,.3,1) 60ms both }
.lk-ya    { animation:fy-ya  560ms cubic-bezier(.16,1,.3,1) 60ms both }
.lk-seam b { animation:fy-seam 260ms ease-out 520ms both }
.splash.out .lockup { animation:fy-lift 420ms cubic-bezier(.4,0,1,1) both }

/* Anyone who asks for less motion gets the settled lockup and a plain fade. */
@media (prefers-reduced-motion:reduce) {
  .lk-for,.lk-ya,.lk-seam b { animation:none }
  .lk-seam b { opacity:0 }
  .splash { animation:fy-fade 200ms both } }

Before you build it

Three things that will bite

iOS launch screens cannot animate

Apple requires a static storyboard. Make it plain white with nothing on it, then play this sequence as the first thing the web layer renders. The handoff is seamless because both grounds are the same white.

Turn off the auto-hide

The config currently has launchAutoHide: true and launchShowDuration: 1200, which hides the native splash on a timer and will cut across this. Set auto-hide to false and call SplashScreen.hide() yourself once the fonts have loaded.

Wait for the fonts

Both faces must be resident before the first frame, or FOR and ya animate in a fallback and snap width when the real ones arrive. Await document.fonts.ready, then start — and self-host the two faces so there is no network on first launch.

Start order

// Nothing is shown until both faces are resident — otherwise the lockup
// animates in a fallback and jumps width mid-flight.
import { SplashScreen } from '@capacitor/splash-screen';

await document.fonts.load('800 54px "Bricolage Grotesque"');
await document.fonts.load('italic 400 54px "Instrument Serif"');
await document.fonts.ready;

splashEl.classList.add('play');     // native ground is still underneath
await SplashScreen.hide();          // hand over mid-animation; no flash

setTimeout(() => splashEl.classList.add('out'), 1180);
setTimeout(() => splashEl.remove(), 1600);

Also set launchShowDuration low rather than to zero — it is the floor before your own code runs, and on a cold start on a slow device it is the only thing covering the gap.
